DAA Algorithm & Problem Statement Documentation

1. Problem Statement

Uncoordinated municipal garbage collection leads to overflowing bins, citizen hygiene issues, fuel waste, and high carbon emissions. This system solves two core challenges: allowing citizens to report overflowing waste with location/photo data, and tracking collection trucks dispatched via an optimal path.

2. DAA Algorithm (Traveling Salesperson & 2-Opt)

Routing garbage trucks through $N$ collection nodes is an instance of the Vehicle Routing Problem (VRP), an NP-Hard problem with $\mathcal{O}(N!)$ brute-force complexity. We implement:

  • Greedy Nearest Neighbor: Chooses the closest unvisited bin at each step ($\mathcal{O}(N^2)$ time, $\mathcal{O}(N)$ space). Priority is given to bins marked 'Critical'.
  • 2-Opt Local Search: Iteratively uncrosses crossing paths by reversing tour segments until no distance reduction is possible ($\mathcal{O}(K \cdot N^2)$).
  • Dijkstra's Algorithm: Finds shortest street paths between junctions ($\mathcal{O}((V+E)\log V)$).

3. MERN Stack Integration

MongoDB stores reports and coordinate waypoints; Express & Node.js provide REST API routes; Frontend provides an interactive cool-white citizen tracker & route visualizer; and Python delivers the high-speed DAA routing engine.

# DAA Nearest Neighbor + 2-Opt Algorithm in Python
import math

def euclidean_dist(p1, p2):
    return math.hypot(p1['x'] - p2['x'], p1['y'] - p2['y'])

def optimize_waste_route(depot, bins):
    unvisited = list(bins)
    curr = depot
    tour = [curr]
    
    # 1. Greedy Nearest Neighbor (O(N^2))
    while unvisited:
        best_idx = 0
        best_cost = float('inf')
        for i, b in enumerate(unvisited):
            dist = euclidean_dist(curr, b)
            # Factor in urgency: Critical bins get 0.7x weight factor
            weight = 0.7 if b['urgency'] == 'Critical' else 1.0
            if dist * weight < best_cost:
                best_cost = dist * weight
                best_idx = i
        next_bin = unvisited.pop(best_idx)
        tour.append(next_bin)
        curr = next_bin
        
    tour.append(depot)
    return tour # Refined with 2-Opt in optimizer.py
